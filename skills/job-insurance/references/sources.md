# Sources

| Source | How | Notes |
|---|---|---|
| Target companies | each company's ATS board (ats-endpoints.md) | list in lanes.yaml target_companies; best signal-to-noise |
| VC portfolio job boards | the portfolio job pages of firms whose companies fit (many run on Getro or Consider) | strong for startups; verify on the company ATS |
| ATS-domain search | `site:job-boards.greenhouse.io OR site:jobs.ashbyhq.com OR site:jobs.lever.co "<title>" remote` | most hits are stale; use to discover boards, then read the board API |
| OpenJobs connector | search_jobs with title, remote option, posted_within_days 7, min salary | when installed |
| Recruiter emails | inbox, last 3 days | real recruiters only; verify the role exists |
| Communities and newsletters | job newsletters the user subscribes to | leads only |
| LinkedIn | read only through search results and the user's own alerts | never automate the LinkedIn site |
