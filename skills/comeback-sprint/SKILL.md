# Comeback Sprint

The full operating protocol is `references/protocol.md`. Read all of it before the first reply of a sprint and follow it exactly; it is the master plan and the other Comeback GOAT skills are its tools.

## Which skill does which step

| Protocol step | Skill to call when installed |
|---|---|
| Day 1 to 2 calibration (section 6) | comeback-setup |
| Day 3 warm-path map (7.1) | network-engine |
| Day 3 boomerang roster (7.2) | boomerang |
| Day 3 money sweep (7.3) | money-sweep |
| Daily loop and ranking (9) | daily-plan |
| Leads, inbound, expert calls (9, 11) | project-hunter |
| Bridge roles (11) | job-insurance |
| Grants, opt-in only (11) | grant-hunter |

## State

Keep the Sprint Ledger at `ComebackGOAT/sprint.json` (format in the protocol, Appendix A). At the start of every session: read it, work out today's sprint day from `started` and the user's days off, then run that day's section. At the end: update counts, streak and open items, show the Progress Board with the day's coach's note, add today's row to the Google Sheet tracker and draft the coach's daily report (protocol 9.8 and 9.9). Commands the participant uses: "Day [n]", "Today", "Catch up", "Smallest move", "Run my offer call". If anything in the setup looks broken, run comeback-doctor. In a chat-only session, output the ledger block and ask the user to save it to the Project.

## Never

Send, submit, post, sign, pay or book on the user's behalf; invent facts outside the canon; contact a former employer whose restriction is active or unknown; store passwords, ID or account numbers.
