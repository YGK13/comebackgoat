# File search patterns (local folder or cloud drive)

Search names first, then contents. Skip folders the user marked private. Never copy account or ID numbers out of a file; record institution, last 4 digits, date and the file path.

| Look for | Name patterns | Content keywords | Lead it creates |
|---|---|---|---|
| Brokerage and bank statements | `statement`, `stmt`, institution names | "cash balance", "core position", "sweep" | forgotten cash balance |
| Retirement statements | `401k`, `pension`, `retirement`, `IRA` | "vested balance", "plan administrator" | stranded retirement money |
| Tax forms | `1099`, `W-2`, `1098`, `K-1` | payer names | every payer is a lead to check |
| Offer letters and plan documents | `offer`, `equity`, `option`, `grant notice`, `bonus plan` | "vesting", "exercise", "acceleration" | equity and bonus deadlines |
| Separation documents | `separation`, `severance`, `release` | "consideration", "revocation" | severance schedule and windows |
| Invoices | `invoice`, `INV-`, `receipt` | "due", "balance" | unpaid receivables |
| Leases and deposits | `lease`, `deposit` | "security deposit", "return within" | deposit owed back |
| Insurance | `EOB`, `claim`, `reimbursement` | "amount owed", "patient responsibility" | unpaid reimbursements |
| Settlement letters | `settlement`, `claim` | "claim ID", "administrator" | open claim windows |

On Windows the user's Documents, Downloads and Desktop folders hold most of these; on Mac the same plus iCloud Drive. Use the device bridge or a connected folder only; never ask for remote access to the whole disk.
