# Public registries

Use official sites only. Search by personal name and every business name, in every state lived or worked in. Stop at any CAPTCHA, login, identity check or claim submission: give the user the link and the step. Verify each URL is still official at run time (the links below are starting points, not guarantees).

## United States

| Registry | Where | Notes |
|---|---|---|
| State unclaimed property, multi-state | missingmoney.com (run by the National Association of Unclaimed Property Administrators) | not every state participates fully; also search each state's own site |
| State unclaimed property, single state | the state treasurer or comptroller site (e.g. New York: Office of the State Comptroller unclaimed funds) | business names separately |
| Retirement Savings Lost and Found | U.S. Department of Labor, Employee Benefits Security Administration | announced Nov 18, 2024; needs Login.gov, so the user signs in |
| Pension Benefit Guaranty Corporation unclaimed pensions | pbgc.gov search | for terminated defined-benefit plans |
| Savings bonds | TreasuryDirect "Treasury Hunt" | matured unredeemed bonds |
| Class-action settlements | court-approved administrator sites named in the notice; reputable settlement lists for discovery only | never pay to file; check the claim deadline |
| IRS refund status | irs.gov "Where's my refund" | user signs in; list only |

## Country module example: Israel (olim and former residents)

| Source | What | How |
|---|---|---|
| Government pension and provident fund locator (Har HaKesef, via the Ministry of Finance) | dormant pension, study fund (keren hishtalmut) and provident fund balances | user signs in with their ID; never ask for the number |
| Fund managers' notices in email | Harel, Menora Mivtachim, Migdal, Phoenix, Clal, Altshuler Shaham, More, Meitav | search sender domains plus Hebrew terms: קרן השתלמות, פנסיה, גמל |
| National Insurance (Bituach Leumi) | unpaid entitlements | user signs in |
| Tax refund (Mas Hachnasa) for salaried years | possible refund on years with partial employment | a tax advisor files; list facts only |

Add a module per country the user names, following the same shape: official locator, provider notices, social insurance, tax refund route.
